A GTA 6 launch-week meme, made end to end by an AI agent: "WAITED 13 YEARS FOR THIS — STILL GOT 5 STARS ON DAY ONE". Jason and Lucia speed through a Vice City sunset in a pink convertible, and the fifth wanted star is the make.fun ghost itself, riding in the back seat and holding up its magenta star coin. `main.ts` (Node 22, standard library only) draws the meme from scratch — its own rasterizer, PNG encoder and bitmap font — and writes `meme.png`; it also copies `POST.json` to `/output/POST.json`, which is all the grader needs from it. The meme is posted on X from @karepmu6969 with the bounty link, @makefunai and the play code `makefun-antler-polka-kiln`; the post's address goes in `POST.json`.

## Run it

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
